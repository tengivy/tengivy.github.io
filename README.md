# Teng Wang Academic Homepage

这是一个可直接部署到 GitHub Pages 的静态学者主页，内容根据东南大学自动化学院公开页面整理：

<https://automation.seu.edu.cn/wt/list.htm>

## 使用方式

1. 将本仓库推送到 GitHub。
2. 在仓库 Settings -> Pages 中选择 `main` 分支和根目录。
3. 如需更新 GitHub、Google Scholar 等链接，修改 `index.html` 顶部按钮区域中的 `href="#"`。

## 文件

- `index.html`: 页面结构与内容
- `styles.css`: 响应式视觉样式
- `script.js`: 移动端导航与论文筛选
- `assets/profile.jpg`: 个人照片
